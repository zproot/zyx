# zyx

Minimal static shell and coreutils for [zproot](https://github.com/zproot/zproot) guests, written in Zig.

## Status

Early. Folder structure in place.

## Build

    zig build -Dtarget=aarch64-linux-android -Doptimize=ReleaseSafe
    zig build -Dtarget=aarch64-linux-musl -Doptimize=ReleaseSafe
